1. 一页结论

Description：Professional video, audio, and photo editing in your browser（package.json:5）

Language：TypeScript 为主（2288 个 .ts + 665 个 .tsx，不含 icons/ 下 6430 个 SVG）

Framework / Runtime：React 19 + Vite 5 + Zustand 4；浏览器运行时，桌面端 Electron 33，云端 Cloudflare Workers/Pages

Architecture：本地优先的浏览器编辑器 monorepo：UI → Store → Bridge → @openreel/core 引擎；旁挂 Agent / Collab / Export / Desktop

Package Manager：pnpm 11.7.0；License：MIT；Node：>=18，CI 使用 Node 22

2. 运行时架构图

下图由 Archify 基于当前仓库的真实源码证据生成，只保留 10 个核心组件和一条主路径：用户 / 本地素材 → React 编辑器 → Zustand 工程状态 → ActionExecutor → RenderBridge → VideoEngine → 浏览器 API。

旁路：AudioEngine 并行调度声音；ExportEngine 按固定时间步导出；AutoSave 异步写入 IndexedDB。

10. 补充观察

  • 本地优先：README 明确“100% Client-Side”“No uploads”“No cloud processing”（README.md:13-19）。
  • Monorepo：package.json:60-63 与 pnpm-workspace.yaml:1-3 均定义 apps/* + packages/*。
  • WASM 是构建前置条件：根 build 先执行 build:wasm（package.json:9-10），AssemblyScript 产物由 packages/core 的 asc 脚本生成。
  • 浏览器能力边界：WebGPU 不可用时回退 Canvas2D；Chrome/Edge 为推荐环境。
  • 图标资源极多：icons/ 下有 6430 个 SVG，因此扩展名统计里 SVG 远高于源码文件数。
  • 未检测到：根级 Dockerfile、docker-compose.yml、ESLint/Prettier 根配置；lint 配置在 apps/web 内。
