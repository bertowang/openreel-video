1. 5 分钟完成第一条视频

打开编辑器首页

浏览器访问 http://localhost:5173（开发模式）或线上地址。首次进入会看到欢迎页 WelcomeScreen。

选择画幅或模板

点击三个大卡片之一：

  • Vertical：竖屏 1080×1920，适合 TikTok / Reels / Shorts。
  • Horizontal：横屏 1920×1080，适合 YouTube / Vimeo / Web。
  • Square：方形 1080×1080，适合 Instagram / Facebook。

也可以点 Browse templates 选模板，点 Use Template 后进入编辑器；或点 Recent projects 打开最近项目。

导入素材

在编辑器按 ⌘/Ctrl+I，或点菜单 File → Import media…；也可以从左侧素材面板点 Import，或把本地视频/音频/图片直接拖进左侧素材区。

把素材放到时间线

从左侧素材面板把素材拖到底部时间线的轨道上。时间线顶部的 Track 下拉可以选择 Dialogue / Music / Captions 等轨道类型。

粗剪

用选择工具 V 选中片段，用刀片工具 B 或 S 在播放头处分割，删除不需要的片段；按 Space 预览。

加点文字和转场

左侧竖栏点 Text & captions 添加文字或自动字幕；点 Transitions 把转场拖到两个片段的接缝处。

导出

点右上角 Export，选择预设或自定义设置，点 Export Video（或先 Add to queue）。

如果页面是英文而你看不惯：当前版本没有中文界面。这不是浏览器语言设置问题，而是代码里尚未实现 i18n。详见 源码分析文档中的说明。

3. 导入与摆放素材

3.1 三种导入方式

  1. 菜单导入：File → Import media… 或 ⌘/Ctrl+I。
  2. 素材面板导入：左侧素材面板顶部有 Search media、Import、Record。
  3. 拖拽导入：从文件管理器把视频/图片/音频拖到左侧素材区。

3.2 放到时间线

  • 从素材面板把素材拖到底部时间线轨道上。
  • 时间线顶部 Track 下拉可切换 Dialogue / Music / Captions 等轨道类型。
  • 拖错轨道可以撤销 ⌘/Ctrl+Z，或用剪切 ⌘/Ctrl+X 后重新粘贴。

3.3 轨道控制

轨道头上有以下按钮：

  • Lock track：锁定轨道，防止误改。
  • Hide track：隐藏轨道画面。
  • Mute track：静音。
  • Solo track：独奏该轨道。
  • Sync Lock：同步锁定。

4.3 变速

选中片段后，在右侧检查器切到 Speed 标签。预设范围为 0.25× 到 5×，也可以填自定义速度；勾选 Apply speed to audio 可让音频一起变速。

删除片段默认会留下空隙；如果你希望后面的片段自动前移，请使用波纹删除（Shift+Delete），不要按普通 Delete。

5. 文字、字幕、音频与特效

5.1 文字与字幕

左侧竖栏点 Text & captions，面板顶部有标签：

  • Text：文字样式。
  • Captions：字幕。
  • Transcript：转录文本。
  • QC：字幕质检。
  • Saved styles：保存的样式。

常用按钮：

  • Add plain text：添加普通文字。
  • TITLES / LOWER THIRDS：标题与下三分之一字幕模板。
  • Auto captions：自动生成字幕。
  • Caption language：选择转写语言。注意这是媒体语言，不是界面语言。
  • Generate captions：开始生成。

5.2 特效与转场

左侧竖栏点 Effects 或 Transitions：

  • 特效面板提示 Effects · Drag onto a clip：把特效拖到片段上。
  • 转场面板提示 Drop on a cut：把转场拖到两个片段的接缝处。
  • 面板顶部有搜索框，可以按名称筛选。

5.3 关键帧与调色

  • 菜单 Effects → Keyframe editor 打开关键帧面板；可复制/粘贴/删除关键帧，并调整 Easing 缓动。
  • 右侧检查器 Color 标签提供曲线、色相曲线等调色工具；快捷键 Shift+S 可切换示波器。

5.4 音频与多机位

  • 菜单 Window → Audio mixer 打开混音器。
  • 菜单 Sequence 下有 Create multi-camera source、Multi-camera monitor、Flatten、Multi-camera editing 等入口。
  • 多机位监视器会叠加在中央预览区上方。

6. AI 对话编辑

6.1 打开对话面板

三种方式：

  • 顶部工具栏切到 AI assist。
  • 左侧竖栏点 AI Editor chat。
  • 菜单 View → AI assist。

如果还没有连接模型，会先弹出连接对话框；未连接时发送按钮不可用。

6.2 输入需求

输入框占位文案是：

Describe an edit… e.g. "make a 9:16 version with captions"

示例提示词：

  • Add captions
  • Make a 9:16 version
  • Balance audio

按 Enter 发送，Shift+Enter 换行。

6.3 确认工具调用与查看更改

  1. AI 返回工具调用卡片后，会显示工具名与参数。
  2. 点 Approve 执行单个操作；Approve all this turn 批准本轮全部；Reject 拒绝。
  3. 右侧检查器会变成 Changes 面板，可点击跳转到具体编辑点。
  4. 不满意可点 Undo all 撤销本轮，或 Keep all 保留。

7. 导出与队列

7.1 打开导出对话框

  • 右上角 Export 按钮。
  • 菜单 File → Export…（⌘/Ctrl+E）。
  • Quick export 子菜单可直接使用预设。

7.2 导出设置

对话框会提示 Choose a ready-made preset or fine-tune every setting.，顶部先选择导出范围：

  • Entire timeline：整条时间线。
  • Marked In/Out：只导出标记的入点与出点之间。

四个页签：

页签用途
Presets现成预设，按平台与推荐场景分类。
Smaller File体积优先，压缩导出。
Custom Settings完全自定义格式、编码、分辨率、码率、帧率。
Images & GIF导出图片序列或 GIF。

常见格式与编码：

  • 容器：MP4 / WebM / MOV；桌面端额外支持 MXF。
  • 视频编码：H.264 / H.265 / ProRes / DNxHR / XDCAM HD422 / AVC-Intra / VP9 / AV1。
  • 音频编码：AAC / MP3 / WAV。

底部按钮：

  • Add to queue：加入导出队列，稍后统一处理。
  • Export Video：立即导出。
  • Smaller File 页签下为 Compress & Export。

7.3 导出队列

点顶部队列图标打开 Export queue 面板，可启动/暂停任务，也可导出 stems（分轨）。

浏览器端无法使用部分专业编码器：ProRes、DNxHR、XDCAM、AVC-Intra、MXF、透明通道、高位深等需要桌面版编码器。导出对话框内会有提示。

8. 保存与恢复

8.1 自动保存

应用默认每 30 秒自动保存一次，保留 3 个槽位，输入停止 2 秒后触发。顶部保存状态会显示：

  • Saved：已保存。
  • Saving…：正在保存。
  • Unsaved：有未保存修改。
  • Save failed：保存失败。

自动保存开关与间隔可以在项目设置的 General 面板调整。

8.2 手动保存与打开

  • 菜单 File → Save（⌘/Ctrl+S）。
  • Save as…（⇧⌘/Ctrl+S）。
  • Save version 保存版本。
  • Open project… 打开项目文件。
  • 项目菜单 Project backups 查看备份。

8.3 崩溃恢复

下次打开时如果发现未保存工程，会弹出 We found an unsaved project 恢复对话框，可选择 Recover 或 Clear all。

10. 移动端与触屏操作

手机判定条件为宽度 ≤600px 且为触摸设备；紧凑平板为 ≤1366px 且触摸。

  • 手机顶部会出现 Back to timeline、Library、AI assist、Clip controls。
  • 紧凑布局底部页签为 Timeline / Media / Edit / AI。
  • 手机底部工具坞包含 Edit / Audio / Text / Captions / Effects / Find tool，以及 Split / Speed / Volume / Animate / Crop / Filters / Replace / Delete 等快捷动作。
  • 手机时间线的 + 菜单对应 Add media。
  • AI 聊天在手机上改为 Sheet 形式；侧栏不再常驻。

手机端会裁剪部分桌面功能，且某些工具会根据选择状态或权限置灰。如果找不到某个专业功能，请换桌面浏览器或使用桌面版。

11. 常见问题

11.1 界面为什么是英文？能切换中文吗？

当前版本没有实现 UI 国际化：没有语言包、没有语言 Provider、没有切换入口，按钮文案硬编码在组件里。Caption language 只是字幕转写语言，不是界面语言。需要开发翻译层后才能支持中文。

11.2 找不到 Motion Creator？

特性开关 MOTION_CREATOR_ENABLED = false，#/motion 会回落到标准编辑器。目前该项未开放。

11.3 AI 对话不能发送？

需要先在 Connect a model 对话框配置 LLM 服务（OpenAI / Anthropic / OpenAI-compatible 等）。未连接时发送按钮禁用。

11.4 导出 ProRes / MXF 失败？

这些专业编码依赖桌面版 ffmpeg 编码器；浏览器端会提示不可用。请使用桌面应用，或改选 H.264 / H.265 / VP9 等浏览器支持的编码。

11.5 预览卡顿或没有 GPU 加速？

应用会在没有 WebGPU 时回退到 Canvas2D；功能仍可用，但 4K 或复杂特效性能下降。建议使用 Chrome/Edge 并开启硬件加速。

11.6 打开页面空白或素材处理异常？

开发部署时可能漏了 pnpm build:wasm。详见 部署与操作指南 的“首次本地部署”章节。

11.7 按钮名称和本文对不上？

本文按当前代码中的英文原文对照编写。若产品后续更新了文案，请以页面实际显示为准，并用 ⌘/Ctrl+K 全局搜索工具名。
